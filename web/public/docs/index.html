What it is

The same reads the Desk app makes, at https://trydesk.trade/api/v1. Everything is public chain data and public profiles, so there is nothing to sign up for and no key to send. Every response is JSON with Access-Control-Allow-Origin: *, so a browser can call it straight from a page.

It is read-only. Nothing here places an order, moves funds or knows a key. Desk’s trading key never leaves the phone it was made on.

Data is on Monad mainnet: Perpl’s exchange contract for positions, a Hypersync-indexed ledger for wallet history, and .nad, nad.fun, ENS and Farcaster for names. The meta.asOf stamp on every answer says when it was read.

Safe inputs

The API takes only things that are already public on chain:

  • Addresses — 0x followed by 40 hex characters. Anything else is refused with invalid_address before any lookup happens.
  • Transaction hashes and token contracts, where a route asks for one.
  • .nad names, resolved to an address on the identity route.

Never send a private key, a seed phrase, a passkey or a signature. No route accepts one, and no route needs one. Anything that asks you for those is not this API.

Endpoints

All routes are GET (and HEAD); OPTIONS answers 204 for preflight. Each shows its rate-limit tier.

GET/api/v1default

The index: name, version, links and the route list.

curl https://trydesk.trade/api/v1
GET/api/v1/traders/top?limit=25default

Traders on Perpl ranked by unrealised PnL across their open positions, with each position’s market, side, leverage and value. limit is 1 to 25.

curl "https://trydesk.trade/api/v1/traders/top?limit=5"
GET/api/v1/traders/{address}/historyexpensive

A trader’s closed trades on Perpl with win rate, profit factor, drawdown, average hold and leverage, and a one-line summary of their style. An address with no Perpl account answers stats: null.

curl https://trydesk.trade/api/v1/traders/0x95d2602d30da1179fd13274839e60345857ca648/history
GET/api/v1/identity/{address}default

Who an address is: a .nad name, a nad.fun profile, an ENS name or the Farcaster account that verified it. Only accounts that verified the address count; a name is never guessed.

curl https://trydesk.trade/api/v1/identity/0x95d2602d30da1179fd13274839e60345857ca648
GET/api/v1/wallets/{address}expensive

Everything Desk knows about a wallet in one answer: identity, holdings on every chain it reads, and its trade ledger on Monad with realised and unrealised PnL. A wallet seen for the first time is indexed on the spot; ledger.status says whether the ledger is complete or still being built.

curl https://trydesk.trade/api/v1/wallets/0x95d2602d30da1179fd13274839e60345857ca648
GET/api/v1/tokens/signals?window=6hdefault

Tokens that tracked wallets have been buying, scored by how many bought, how much net, how early and how concentrated. window is 1h, 6h or 24h.

curl "https://trydesk.trade/api/v1/tokens/signals?window=24h"
GET/api/v1/healthdefault

Service health in the application/health+json shape: Redis, Monad RPC, Perpl, the indexing worker and the alerts cron. 200 on pass or warn, 503 on fail. Rendered at /status.

curl -i https://trydesk.trade/api/v1/health
GET/api/v1/statsdefault

Counters only: requests served today, wallets being tracked, alert subscriptions. No addresses, ever.

curl https://trydesk.trade/api/v1/stats

Response envelope

Every successful answer wraps its payload the same way. cached is true when the answer came from the server’s own memo rather than a fresh read.

{
  "data": { ... },
  "meta": {
    "asOf": "2026-09-21T12:00:30.000Z",
    "chain": "monad",
    "cached": false
  }
}

Answers also carry a Cache-Control that says how long a shared cache may keep them: 30 seconds for the top list, 60 for history, identity and wallets, 15 for signals, and never for health or errors.

Errors

Errors are RFC 9457 Problem Details, served as application/problem+json with Cache-Control: no-store. The code field is stable; match on it rather than on detail.

{
  "type": "https://trydesk.trade/docs#error-invalid_address",
  "title": "Invalid address",
  "status": 400,
  "detail": "Addresses are 0x followed by 40 hex characters.",
  "instance": "/api/v1/identity/0x1234",
  "code": "invalid_address"
}
CodeStatusWhen
invalid_address400The address in the path is not 0x + 40 hex characters.
invalid_request400A query parameter is out of range, such as an unknown window.
not_found404The address is valid but nothing is known about it.
unknown_route404No such path under /api/v1.
method_not_allowed405Only GET, HEAD and OPTIONS are served.
rate_limited429Over the tier’s limit. Retry-After says how long to wait.
upstream_unavailable503Monad, Perpl or the store could not be read. Retry with backoff.

Rate limits

Limits are per client IP over a sliding minute. Two tiers: default is 60 requests a minute; expensive routes (history and wallets, which read the chain) are 10. Every answer, including errors, carries the tier’s headers.

HeaderMeaning
X-RateLimit-LimitRequests allowed per minute on this route’s tier.
X-RateLimit-RemainingHow many are left in the current window, 0 when over.
X-RateLimit-ResetUnix seconds when the current window resets.
Retry-AfterOnly on 429: seconds to wait before trying again.

Shared caches in front of the API mean a popular answer is often served without touching your quota. If you need more, cache on your side using meta.asOf and the Cache-Control hints, and open an issue if that is not enough.
