Face ID + Perpl

No server can trade for anyone.

The key is never on a server

It exists only in the app’s memory, only while it is open and unlocked. Ours pushes notifications and reads public chain data — nothing it holds could move your money.

Monad and Perpl

Orders are signed on the device and sent over Perpl’s websocket, deadline-bound to the head block so a stale one cannot fill late. A position event on Monad wakes the copy loop in the same block the trader moved in.

Your money. Your key.

No server holds a key that can move it. That is the reason live copying needs Desk open, and it is a deliberate trade rather than a shortcut.
